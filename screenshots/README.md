# Site screenshots

A record of how the site looked at each redesign. This folder sits outside
`docs/`, so it is not published on katiek.im.

## 2026-11-17 — notebook redesign

- `before/` — the site on `master` just before the redesign: one full-page
  desktop screenshot (1280px wide) per page. The old top nav bar is missing
  from these captures because it loaded jQuery from code.jquery.com, which
  was not reachable when the screenshots were taken; on the live site it
  appeared as a blue bar along the top.
- `after/` — the redesigned site, every tab, on desktop (1280×900) and
  phone (390×844), numbered in tab order.
